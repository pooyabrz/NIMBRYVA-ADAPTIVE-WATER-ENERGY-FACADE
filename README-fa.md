# نمای تطبیقی آب و انرژی - گزارش قابل ارائه F1

**این نسخه روی فایل پیوست مرحلهٔ B شما اعمال شده است و تمام تغییرات و نتایج C/D/E را دارد.** گزارش تازه، حسابداری منشأ آب و انرژی و آزمون هوای جدید ۲۰۲۵ نیز افزوده شد. [گزارش PDF](output/pdf/Defensible-Report-fa.pdf)، [گزارش HTML مستقل](output/presentation/report-fa.html) و [روش و اجرای محلی](docs/PRESENTATION-fa.md) در دسترس‌اند.

```bash
python -m pip install -r requirements.txt
python run.py presentation check
python run.py presentation view
```

نمای سه‌بعدی با پایتون روی رایانهٔ شما اجرا می‌شود. داده‌های جدید پنج کنترل را نشان می‌دهد؛ خطوط پیوسته، آغازهای مشترک در دامنهٔ محاسباتی و خطوط نقطه‌چین، ادامهٔ صرفاً تشخیصی‌اند. نتایج قدیمی جدا حفظ شده‌اند. نتایج جدید، ظرفیت سالانهٔ تأییدشده یا برتری RL را نشان نمی‌دهند.

برای ساخت مجدد گزارش: `pip install -r requirements-presentation.txt` سپس `python run.py presentation report`. برای بازاجرای PPO/MPC به وابستگی‌های `requirements-research.txt` هم نیاز است. فونت و مجوز لازم همراه پروژه‌اند.

**تحویل C/D/E:** آزمون‌های شبکه/زمان، دادهٔ تجربی مستقل PV/شبنم/باران، ۲۰ فایل سالانهٔ تازه، مدل جانشین و سه آموزش PPO واقعاً اجرا شدند. نتیجه هنوز دقت بالای کل محصول یا برتری RL را تأیید نمی‌کند. [نتایج و حدود ادعا](docs/CDE-RESULTS-fa.md)، [اجرای محلی](docs/CDE-RUN-fa.md) و [منابع اولیه](docs/CDE-SOURCES.md) را بخوانید.

```bash
python -m pip install -r requirements-research.txt
python run.py research check
python run.py research view --source teacher
```

فرمان سوم نمایش سه‌بعدی پایتون را روی رایانهٔ شما باز می‌کند؛ شهر/پنجره، کنترل‌کننده و ساعت قابل تغییرند. فایل‌های آموزش‌دیده در `results/research/E/` هستند. محیط پژوهشی جدید ۵۰ ورودی دارد و از محیط مستقیم ۴۸ورودی مرحلهٔ A جداست.

این نسخه روی پروژهٔ ارسالی شما اعمال شده است. دادهٔ آمادهٔ سال ۲۰۲۴ هر ۱۲ شهر و فایل‌های خام آن حفظ شده‌اند. کد، مدل و سیاست PPO قبلی در `legacy_v1/` آرشیو هستند؛ سیاست قبلی با مدل جدید سازگار نیست.

**وضعیت:** مدل محاسباتی کاست برای غربالگری و بررسی حساسیت، با داده‌های مستند و شکاف‌های صریح. این بسته هنوز یک دوقلوی دیجیتال اعتبارسنجی‌شده یا شبیه‌سازی کامل CFD/انتقال تابش جوی نیست. نتیجهٔ مشروط شبیه‌سازی، ظرفیت تضمین‌شدهٔ دستگاه نیست.

**افزودهٔ مرحلهٔ B:** حل واقعی OpenCFD 2312 در سه شبکهٔ ساختمان/کاست، آزمون ABL، ردیابی باران چنداندازه، حل مستقل دیوار/زمین در ۱۲ شهر، فیلم آب و آنتالپی یخ/برف و مرجع تحلیلی استفان. [روش و حدود مدل](docs/STAGE-B-fa.md)، [نتایج اجرا](docs/STAGE-B-RESULTS-fa.md) و [راهنمای اجرای محلی](docs/STAGE-B-RUN-fa.md) را بخوانید. گزارش‌های قدیمی کاست ۲، نتایج مرحلهٔ A هستند؛ محیط PPO قبلی هنوز برای سرما و برف پشتیبانی نشده است.

```bash
python run.py stage-b check
python run.py stage-b view --case results/stage-b/cfd/reference-medium
```

نمای مرحلهٔ B از میدان واقعی CFD استفاده می‌کند. برای آن به نصب OpenFOAM نیاز ندارید؛ بازسازی حل CFD به نسخهٔ تثبیت‌شده در راهنمای بالا نیاز دارد. گشتاور فشار، ضریب انتقال جرم و سناریوی پاشش در این مرجع، تأیید نهایی دستگاه نیستند.

## اجرا روی رایانهٔ شما

Python 3.11 یا 3.12 و Matplotlib با پشتیبانی پنجرهٔ دسکتاپ:

```bash
python -m venv .venv
```

Windows: `.venv\Scripts\activate.bat` ؛ Linux/macOS: `source .venv/bin/activate`

```bash
python -m pip install -r requirements.txt
python run.py check
python run.py audit
python run.py view --city rasht
```

نمایش سه‌بعدی کاملاً با پایتون و روی سیستم شماست. در این بسته تصویر سه‌بعدی آماده یا نمایش ابری ساخته نشده است. ماوس صحنه را می‌چرخاند؛ می‌توانید شهر، زاویه، ارتفاع نصب، سطح رو به بالا، تفکیک لایه‌ها و پیش‌نمایش حرکت را تغییر دهید. سرعت پیش‌نمایش بیشتر از حرکت واقعی است و زمان فیزیکی در پنجره نوشته می‌شود. بردارهای هوا و مسیر آب مفهومی‌اند.

مشخصات و حدود ادعا در `docs/ENGINEERING-fa.md`، معادلات و فرض‌های حل در `docs/METHOD.md`، وضعیت پنج شکاف در `results/cassette-v2/evidence-audit.json` و نتیجهٔ اجراها در `docs/RESULTS-fa.md` آمده است. جدول پارامترهای فعال: `config/evidence/active-parameters.csv`.

## آزمایش‌های قابل بازتولید

```bash
# آزمایش کوتاه: هر ۱۲ شهر، دو کنترل، ۴۸ ساعت با ۲۴ ساعت گرم‌سازی
python run.py benchmark --months 7 --hours 48 --warmup 24

# چهار فصل؛ پیش‌فرض ۹۶ ساعت و ۲۴ ساعت گرم‌سازی در هر مورد
python run.py benchmark

# حساسیت پارامترها؛ هر خروجی وابسته به سناریو است
python run.py uncertainty --cities rasht singapore dubai la-paz

# حساسیت گام زمانی و جابه‌جایی زمانی تابش بلندموج
python run.py sensitivity

# بررسی محلی رابط گرافیکی بدون باز کردن پنجره
python run.py view --check

# این فرمان به‌درستی با کد خروج ۲ تمام می‌شود: شواهد نهایی کافی نیست
python run.py audit --strict
```

خروجی‌های نسخهٔ جدید در `results/cassette-v2/` هستند. `drain_L` خروجی شرطی مدل با تقریب یک کیلوگرم آب برابر یک لیتر است. `water_supported` فقط پشتیبانی از رژیم محاسباتی آب مایع را نشان می‌دهد؛ `physical_yield_claim_supported` همیشه نادرست است. آب خروجی برای آشامیدن ارزیابی نشده است.

اگر حتی یک ساعت پنجره شامل یخ‌زدگی، برف، میعان حل‌نشده روی دیوارهٔ دیگر کانال، حالت رطوبتی خارج از دامنه یا عبور مکانیکی از ظرفیت باشد، خروجی قابل امتیازدهی آن پنجره کنار گذاشته می‌شود. ستون `conditional_drain_L` برای عیب‌یابی باقی می‌ماند و نباید به‌عنوان عملکرد معتبر استفاده شود. خیس شدن بیرون گسیلنده نیز جدا علامت می‌خورد چون طیف سطح خیس موجود نیست.

## یادگیری تقویتی

```bash
python -m pip install -r requirements-rl.txt
python run.py train --steps 100000 --seed 7
```

فرمان `train` بالا هنوز مسیر مستقیم مدل ۴۸ورودی مرحلهٔ A است. **PPO پژوهشی مرحلهٔ E آموزش داده شده است:** سه بذر، هرکدام ۵۰۱۷۶ گام در جانشین ۵۰ورودی، با فرمان‌های سند CDE. آموزش قدیمی ۲۷ ورودی داشت و به مدل دوگرهی مربوط است؛ اجرای آن در ارزیابی جدید رد می‌شود. محیط فقط اطلاعات موجود در زمان تصمیم را می‌دهد، سپس با هوای بازهٔ بعد پیش می‌رود. حفاظت محلی از باد و انرژی می‌تواند درخواست عامل را رد کند. PPO معمولی احتمال اعمال را مستقیماً ماسک نمی‌کند؛ ماسک در مشاهده آمده و حفاظت در حل‌گر اعمال می‌شود. این حفاظت معادل تأیید ایمنی سازه نیست.

## دادهٔ طیفی بیرونی

قالب و محدودیت‌ها در `docs/SPECTRAL-INPUT.md` مشخص است. دادهٔ سالانهٔ فعلی ERA5/NASA، طیف جوی ساعتی نیست. ضریب‌زدن طیف مرجع ASTM به تابش ساعتی، بازسازی طیف واقعی شهر به شمار نمی‌رود. رابط ورودی برای خروجی یک محاسبهٔ جوی مستند آماده است؛ libRadtran در این تحویل اجرا نشده است.
